# Free BMI Calculator

A simple, responsive **BMI (Body Mass Index) calculator** built with **HTML, CSS, and JavaScript**.  

This calculator allows users to:

- Calculate BMI using **Metric** (kg, cm) or **Imperial** (lb, in) units  
- See BMI category (Underweight, Normal, Overweight, Obesity)  
- View the **ideal weight range** for your height  
- Store calculation history locally in your browser  
- Download history as a CSV file  

---

## ✅ Features

- Fully **offline-friendly**  
- Mobile and desktop responsive  
- Easy to use and completely **free**  
- SEO-friendly for Google search (when hosted)  

---

## 📌 How to Use

1. Go to the **live site**: [https://yourusername.github.io/bmi-calculator/](https://yourusername.github.io/bmi-calculator/)  
2. Select units (Metric or Imperial)  
3. Enter your **weight** and **height**  
4. Click **Calculate BMI**  
5. Optionally, save to history or download history as CSV

## 💻 How to Run Locally

1. Clone or download this repository  
2. Open `index.html` in your browser  
3. Enjoy the calculator offline
